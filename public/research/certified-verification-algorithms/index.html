Certified Verification Algorithms for Continuous Dynamics

April 20, 2026 · 153 words · Me

Overview#

Numerical algorithms for analyzing dynamical systems are inherently approximate. This project aims to bridge the gap between efficient numerical computation and formal guarantees by developing certified algorithms with machine-checked proofs of correctness.

Background#

Traditional numerical methods for reachability analysis, stability verification, and controller synthesis rely on floating-point arithmetic and approximations. While efficient, these methods can produce incorrect results due to rounding errors or discretization artifacts.

Formal verification offers mathematical guarantees but often at prohibitive computational cost.

Approach#

We pursue a multi-faceted approach:

  • Interval arithmetic with formal error bounds
  • Taylor model methods for validated integration of ODEs
  • Formalization in proof s such as Lean and Coq
  • Extraction of certified code from formal proofs

Results#

  • Formally verified interval Newton method for root finding
  • Certified Lyapunov function computation for stability analysis
  • Integration with the KeYmaera X theorem prover

Future Work#

Plans include extending to partial differential equations and developing certified machine learning components for control.
