## Course Description

Graduate seminar covering advanced topics in hybrid systems including differential dynamic logic, reachability analysis, and controller synthesis.

## Topics Covered

- Hybrid Automata: Models and Semantics
- Differential Dynamic Logic
- Reachability Analysis for Linear and Nonlinear Systems
- Formal Synthesis of Hybrid Controllers
- Case Studies: Automotive, Robotics, Cyber-Physical Systems

## Responsibilities

- Delivered 4 lectures on differential dynamic logic
- Supervised student projects on formal verification tools
